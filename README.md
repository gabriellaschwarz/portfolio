## AI Use

I used Claude Code to help me build this site. It helped me write the starter HTML, CSS, and D3 chart code, which I reviewed, revised, and edited. This was helpful to both save me time but also to better understand elements I missed during the lecture, and ensured my code was neat. I made all the custom styling choices myself and kept it simple due to my lmited CSS/HTML knowledge. I used code also from my portfolio page for the main body styling and colors, which is also where I got the inspiration to add color and font variables which makes modifying them easier, because it only needs to happen in one place.

I wrote all the text myself, and added my own images. I used the most help with the D3 chart because it was unfamiliar territory to me. I copied the code from the d3 website as stated in the chart.js file as I used the stacked barchart code. I also had Claude help me clean my data, because I merged 15 RSVP data csvs together and calculated the returning members -- a very useful use of AI! This would have taken me ages, yet the data was cleaned and in a ready to use CSV in mere seconds using Claude. The decision about what chart to make and how to arrange it (which laters to stack, x and y axis, legend, etc. were all my own).

I also used clause to help me identify excessive lines of code that were going unused. I removed these to neaten up the code in my previous commit.

Overall this assignment was a great opportunity to practice my AI collaboration skills, both learning the ropes of building the site myself, but also utilizing AI where it is very helpful.
